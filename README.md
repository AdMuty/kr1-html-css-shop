# TURIST bezgranits

Учебный проект туристического агентства. Многостраничный сайт
с каталогом туров, страницами тура, заявки и контактов.

## Ссылка на опубликованный проект

GitHub Pages: https://admuty.github.io/kr1-html-css-shop/

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В рамках КР №1 разработан многостраничный HTML/CSS-сайт
туристического агентства TURIST bezgranits.

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог туров;
- `product.html` – страница тура;
- `order.html` – оформление заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – файл JavaScript;
- `images/` – папка для изображений;
- `README.md` – описание проекта;
- `.gitignore` – список файлов, исключённых из Git.

## Используемые технологии

- HTML;
- CSS;
- JavaScript;
- Git;
- GitHub.

## Реализованные элементы

- 3 популярных тура на главной странице;
- 9 туров в каталоге с фильтрами;
- карточки туров с картинками;
- страница тура с таблицей характеристик;
- модальное окно заявки на главной;
- форма заявки с полями и валидацией;
- маска телефона через JavaScript;
- карта офиса на странице контактов;
- БЭМ-именование классов.

## CSS-архитектура

В проекте используются:

- CSS-переменные в `:root`;
- единая шкала отступов;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- подсветка ошибочных полей через `aria-invalid`;
- Flexbox для навигации и карточек;
- CSS Grid для сетки туров и каталога;
- позиционирование `relative`, `absolute`, `sticky`.

## БЭМ-структура

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной;
- `advantage-card` — карточка преимущества;
- `products-grid` — сетка туров;
- `product-card` — карточка тура;
- `catalog-layout` — каталог с фильтрами;
- `product-detail` — страница тура;
- `product-table` — таблица характеристик;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка;
- `site-footer` — подвал.
